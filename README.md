# Intuit Interview Question Scraper (SerpApi)

This scraper collects technical interview questions for Intuit/Glider from:

- Reddit
- LeetCode
- Glassdoor
- Blind
- GitHub
- Blogs

## Setup

1. npm install
2. Add SERPAPI_KEY to .env
3. Run:
   node index.js

## Output

- Prints 15–20 commonly asked interview questions.
